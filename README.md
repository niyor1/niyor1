# 🚀 Featured Projects

### 🧠 FPL-pro - Transfer-Recommendation Fine-Tuning Pipeline
Fine-tuned Qwen3.5 with LoRA (using MLX) so Fantasy Premier League transfer advice is based on real statistics, **cutting numeric hallucination by 42%**. Matched FPL API data with expected goals/assists across 543 players using exact and fuzzy string logic, and validated synthetic training data from a local 32B teacher model against a deterministic transfer optimiser.
`Python` `LoRA` `MLX`

### 🎁 Giftly - AI-Powered Gift Recommendation App
Full-stack app that turns a plain-English description of someone into personalised gift ideas using the Gemini API, with live UK prices and purchase links from SerpApi. CI/CD with GitHub Actions and Vercel, and **85.8% average test coverage** with Vitest and React Testing Library.
`React 19` `Tailwind CSS` `Vite` `Gemini API`

### 🩺 Gut Health Monitoring App (for Ferryx)
Led a team of 4 to deliver a cross-platform Flutter app that replaced email surveys in a 12-week clinical trial. I built the Spring Boot REST API and PostgreSQL backend on AWS EC2, secured participant data (TLS, hashed storage), and added Firebase push reminders that **lifted survey completion by 50%**.
`Flutter` `Spring Boot` `PostgreSQL` `AWS` `Firebase`
